# complaint

One complaint in full: details, deadlines, contacts and history.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs complaint <ref or name> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Read this before drafting anything about the complaint. If the match is ambiguous, list the candidates and ask. Nothing here sends a letter, an email or a report.
