# link-systemic

Link a complaint to a systemic issue.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs link-systemic <ref> --issue=<SI code> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Report the issue count back. Nothing here sends a letter, an email or a report.
