# report-systemic

Record that a systemic issue went to the board or the owner your policy names.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs report-systemic <SI code> --to="<who>" --on=<YYYY-MM-DD> --root-cause="<cause>" --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Only after it has actually been reported. Nothing here sends a letter, an email or a report.
