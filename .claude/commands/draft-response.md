# draft-response

Draft the written IDR response (AU) or final response (NZ) with the AFCA or FSCL details.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs draft-response <ref> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Read /complaint first. Fill every bracket from the record. Never send it; a person does. Nothing here sends a letter, an email or a report.
