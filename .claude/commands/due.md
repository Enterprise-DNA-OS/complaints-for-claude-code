# due

Responses due in the next N days (default 14).

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs due --days=<n> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Group by owner. Say which ones need a delay notice drafted today. Nothing here sends a letter, an email or a report.
