# weekly-review

Draft the Monday complaints review from attention, due and compliance.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs weekly-review --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Read the draft back in five lines: overdue, due this week, breaches, systemic, ASIC report. Nothing here sends a letter, an email or a report.
