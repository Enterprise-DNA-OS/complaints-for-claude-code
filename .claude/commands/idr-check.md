# idr-check

Gaps that would weaken the ASIC IDR report for a period.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs idr-check <period> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Fix the gaps with the record commands before running /idr-report. Nothing here sends a letter, an email or a report.
