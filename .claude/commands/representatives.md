# representatives

Complaints about authorised or credit representatives.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs representatives --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Point out any representative with more than one complaint. Nothing here sends a letter, an email or a report.
