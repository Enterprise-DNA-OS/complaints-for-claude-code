# periods

ASIC IDR reporting periods: due dates, lodgements and complaint counts.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs periods --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Flag any period that has ended and is not lodged. Nothing here sends a letter, an email or a report.
