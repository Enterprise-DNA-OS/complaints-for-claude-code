# raise-systemic

Raise a systemic issue when complaints point at the same cause.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs raise-systemic --title="<title>" --description="<what the complaints show>" --owner=<name> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Then link the complaints with /link-systemic. Nothing here sends a letter, an email or a report.
