# draft-delay

Draft a delay notice (AU) or notice of extension (NZ).

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs draft-delay <ref> --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. It must reach the complainant before the deadline. Never send it. Nothing here sends a letter, an email or a report.
