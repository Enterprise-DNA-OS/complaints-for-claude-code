# add-holiday

Record a public holiday so business day deadlines skip it.

Read fresh data. Never invent a complaint, a date, a remedy or command output. Complaints hold personal information: keep output inside the business.

```bash
node scripts/complaints.mjs add-holiday --day=<YYYY-MM-DD> --name="<holiday>" --json
```

Replace angle-bracket placeholders with what the person told you; leave out optional flags they did not ask for. If a name or reference is ambiguous, list the candidates and ask. Add the year's national and regional holidays each January. Nothing here sends a letter, an email or a report.
